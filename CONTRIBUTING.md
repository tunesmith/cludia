# Contributing

Thanks for your interest in Cludia.

Bug reports, feature requests, and design discussion are welcome through GitHub
issues. KeenWorks is not currently accepting code pull requests. This keeps
copyright ownership and future licensing options straightforward while the
project's contribution policy is still being established.

Please do not submit implementation patches or pull requests unless KeenWorks
has invited that specific contribution. A contributor license agreement or
other relicensing policy will be documented before outside code contributions
are accepted.

Small reproductions are especially helpful. When possible, include the output
of `cludia version`, the command you ran, and a minimal `.arg` file that
demonstrates the problem. Do not include confidential inquiry material.
